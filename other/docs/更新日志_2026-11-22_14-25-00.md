## 场景匹配：按时段 / 天气 / 细节，不再"差不多就沿用"

- 模型经常只写地点不写时间/天气（`<scene>学校大门口</scene>`），以前会沿用上一张背景的
  时段与天气，于是「白天去学校」出晚上的校门口、「雪停了」还挂着雪景。
- 新增 `scene_cg.time_hint()` / `weather_hint()` / `detail_hint()`：从玩家这句话和这轮动作
  描写里读线索（取最靠后的提及），传给 `match(scene, prev, time_hint=, weather_hint=,
  detail_hints=)`；模型写了标签时以标签为准。
- 细节词表**直接从 `index.json` 的 state 长出来**（开灯/熄灯/空无一人/人来人往…），
  以后加素材不用改代码。
- 提示词补两条：这一轮说了时段或天气，就必须写进 `<scene>`。
- 实测：`早上了，我走去学校门口`（上一张是「站台（晚上）」）→ 学校大门口（白天）（人来人往）；
  `雪停了，薄雪化了一半`（上一张是「街上·白雪皑皑」）→ 街上（晚上）（人行道）（薄雪）；
  没提线索时仍按上一张延续（连续性没坏）。

## 场景匹配：模型判场景（标签对不上也能切）

- 新增 `_judge_scene()`：玩家这句有地点线索时，额外问一次主模型「此刻在哪儿」，
  给它**完整场景名表**（带房间细节），让它挑最接近的一张；和当前不同才切。
- 实测：`我在和纱家别墅的卫生间里洗漱` → 自己的公寓（洗手台）；
  `放学了，我正在回家的路上` → 回家的路（晚上）（路灯亮着）；
  `今天真的好累啊` → 不变。
- 判定调用必须关思考（thinking 字段 disabled），否则 40 个 token 全被 reasoning 吃掉、
  content 为空（线上报过 `bad_response: content 为空`）。

## 配音：旁白不念、读档不串角色

- 整段旁白/动作描写不再送去合成（以前会把「（她在路灯下停了一瞬…）」翻成日语念出来，
  日志里出现过 900KB 的音频）。
- 多角色路径与预合成共用同一套「这一句该用哪个情绪参考」的判断，避免三条路各算各的。
- 读档最后一条按「旁白 / 他人 / 自己」区分显示与配音（以前不管是什么都当当前角色的台词）。
- 新增参考音频导入工具 `tools/import_voice_refs.py`（剧本原文优先、缺的用 ASR 补），
  `tools/ref_vad_scan.py` 支持 `--char` 指定角色。

## 语音：回放不再重新加载

- 合成前**先查缓存**（key 只看文本 / 参考音频签名 / 参数签名，不需要加载权重），
  命中就直接返回；以前是先切权重（3~7 秒）再看缓存，回想里重放一句听过的台词
  看起来就像「重新加载」。
- 修进程池端口撞车：每个角色的语音子进程以前用 9881，和翻译服务 `T_PORT` 同一个端口，
  绑不上 → 该角色一直被标「进程不可用」→ 退回共享进程反复切权重。
  基端口改 9882；分配端口时跳过已被占用的（崩溃留下的孤儿进程会一直 listen）；
  就绪判断从「TCP 连得上」改成 HTTP 健康检查（`404` 也算就绪，只把 5xx/连接失败当没起）。
- `_char_key(cid)` 以前无视传入的角色、永远返回「当前激活角色」；
  `stop()` 以前只收共享进程，池子里的子进程会挂成孤儿占端口。都修了。
- 实测：和纱 9882 / 雪菜 9883 各自独立；冷门台词首次约 10 秒（含子进程加载权重），
  之后重放 0.001 秒；`stop()` 后端口释放、无残留。

## 界面：动作文本改回字模

- 括号里的动作/心理描写改回**字模渲染**，并且是**按行折的多行图**：字号与对话框一致
  （28px 字模 × TEXT_SCALE，约 17.5px）、白字带描边、不压缩不裁切。
- 修复前两版的问题：先是被单行图挤成小字、后来退回系统字体、颜色是蓝的。

## 模型接入：OpenCode Go

- 支持 `https://opencode.ai/inference/go`（OpenAI 兼容）：补 `x-opencode-session` 头，
  自定义 UA；Go 与按量付费的 base URL 不同，走错会得到空 400。
- 会思考的模型（deepseek 系列）自动关思考，避免 content 为空。
- 模型访问受限（403 `permission_error`）时日志写明端点/模型/错误类型。

## 数据目录

  角色的空数据（用户看到「雪菜角色文件夹突然没了」）。现在源码树优先用 `build_env/`。
