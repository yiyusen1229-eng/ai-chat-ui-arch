# 更新日志 · 2026-11-09

（自 `2026-11-08.1` 之后）

## 多角色与导演（框架 + 接入模型）

- 新增「多角色」体系：一场戏里可以同时安排多个角色，由导演负责调度谁在什么时候说话。
- 导演真的会调模型：按「角色卡 + 玩家给的剧情走向 + 第几拍」生成台词与旁白，解析后入队播放。
- 输出契约是 JSON；解析做了三层容错（整段 JSON → 抠出完整对象 → 逐行「名字：「…」」），
  说话人不在阵容里的会被丢弃，超长台词截到最近一句完整的话。
- 角色卡（`card/director.md`）就是导演看到的压缩卡：性格 3 条 / 口吻 3 条 / 绝对不会做的事。
  没有角色卡的角色不能加入多角色场次。
- 阵容里可以加「玩家」，导演会给玩家写台词。

## 标题栏「多角色」控制台

- 标题栏新增「多角色」菜单：连接状态、阵容、队列、开关、长度、导演模型、写一拍、刷新。
- 「导演模型…」与角色模型用同一个对话框：端点 / API 密钥 / 模型名称（连接后自动探测）。
- 面板点开不会一点就关，方便连着调。

## 角色级模型与语音

- 每个角色可以有自己的聊天模型与语音配置，存在角色目录的 `model.json`。
- 模型对话框改成全局可用（从特别模式里搬出来），带「切换连接 / 断开连接 / 连接」；
  连接成功后按钮直接显示「已连接」。
- 语音权重改为跟着角色包走：`characters/<id>/voice_model/` 放 `.ckpt` + `.pth`，
  切角色时热切换；没有权重的角色走预训练底模（零样本），不会借用别的角色的音色。
- 角色包导出/导入带上 `voice_model/` 与 `card/`，别人导出的包导入后立绘、语音、角色卡、权重齐全。

## 对话框显示规则

- 角色台词统一包「」，旁白不包、不显示名字；名字写在名字牌上，和文字同时出现。
- 旁白不再重复显示在左上角动作区；读档恢复的那一句也会补「」。
- 左上角动作文字的字号固定成与对话框一致，不再随长度忽大忽小。

## 播放与节奏

- 新增播放队列：导演排好的「拍」由前端逐条取，按字数 300ms/字 停留；有语音时等语音播完。
- 多角色开启时，自动续说不再并行自己调模型，避免两套系统同时写画面。
