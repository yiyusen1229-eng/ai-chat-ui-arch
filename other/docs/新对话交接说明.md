## 二、怎么跑

```powershell
# 正常启动（会先同步 src → build_env，再开窗口）；--sync-only 只同步不启动
program\启动程序.bat

# 只起后端（调接口 / 自测用）。注意要指素材目录：
cd program\build_env
$env:WA2_ASSETS_DIR = "E:\...\program\res\assets"
.\venv\Scripts\python.exe main.py --serve-only --port 8791
```

- `--port` 真的生效；不指定则 8771 → 8772 → 随机
- **只起后端时必须带 `WA2_ASSETS_DIR`**，否则 `/game/assets/**` 找不到（打包版不用）
- 前端改动后：`Copy-Item src\ui\* build_env\ui2\ -Force -Recurse` **并且 bump `index.html` 的 `?v=`**
- `build_env/` 是运行时目录：`prefs.json` / `memory.json` / `char/` / `sessions/` / `cache/` 都在这里
- **人设 / 世界书**在 `program/src/persona/`、`program/src/worldbook/`（旧根目录的文件也认）

**本地测试包**（含素材与角色资源，不含存档）：

```powershell
cd program
.\build_env\venv\Scripts\python.exe tools\build_portable.py
# 产物：release\和纱_本地测试\  和  release\和纱_本地测试.zip
```

- 目录里 `config.json` 是本地用的（复制自 `build_env\config.json`）；**zip 里没有**，只有 `config.example.json`
- 不含 `sessions/`（存档）、`cache/`、`logs/`、`text_cache`
- TTS 模型没进包；本地在包目录下建了 `tts` 目录联接指向 `other/dev/tts`，换机器语音不可用
- 场景背景图不在仓库里：换机器后跑一次
  `python tools\import_cg.py --src <场景原图目录>` 生成 `res/assets/cg/`（119 张 / 13MB，见 `场景CG系统.md`）
- 缺素材先跑 `python tools\check_assets.py`，它会告诉你缺什么、该放哪

## 十三、问答记录（2026-11-02）

**问：特别模式导入的资源，现在真的生效吗？**
答：都生效了。原则是「程序优先读 `char/`，删掉回落默认」——提示词替换人设、
世界书按关键词触发（`.txt` 整段附加）、记忆书每轮作为**角色固定设定**注入、
参考音频优先用于合成、立绘按变化编号自动补表情。面板底部会显示「当前：xxx（默认/已导入）」，
点「查看文件」打开的就是实际生效的那一份。

**问：世界书和记忆书到底装的是什么？**
答：世界书是**手写的 9 条设定**（2267 字），关键词触发，每轮最多 4 条 / 1200 字，
不是整部剧本。整部剧本在 `story_index.json.gz`（4592 块 / 408 万字），由 `story_rag`
按问题检索，命中才注入 ≤900 字。特别模式的「记忆书」是**常驻记忆书**（角色固定设定，
用户导入，`char/memory/`，现在是空的）；自动的「对话记忆书」是这局对话的摘要，
存在存档 + `cache/memory_runtime.json`。

**问：两套记忆书会不会混？**
答：不会。system 的拼装顺序是：
人设 → 常驻记忆书（`你记得的旧事`）→ 世界书 → 对话记忆书（`你记得的事`）→ 原作片段。
措辞和位置都是分开的。

**问：读超长档的时候，存档里的记忆书和缓存记忆书怎么衔接？**
答：读档时 `memory.seed_from_save()` 把存档 `memory` 整份**复制**到
`cache/memory_runtime.json`，之后整局只读缓存；聊天时超阈值就发「最近段 + 缓存条目」，
每 6 轮把新折叠的一段压进缓存；存档时把缓存整份快照回 `memory` 字段（不再跑总结）。

**问：语音不是能听到吗？**
答：是，能听到。参考音频**不是固定的**：`load_refs()` 扫 `tts/refs_touma/<情绪>/` 和
`char/voice/`，`pick_ref(emo)` 按情绪分组随机挑一条；导入的优先。

**问：现在接的是真实价格吗？**
答：是。右下角花费和特别模式的每轮预估都走 `pricing.py`（含高峰时段、cache 命中价），
不再是前端常数。

| 谁写 | 人手写（现在 18 条） | 从世界书提炼（现在 252 字） | 工具从剧本切块 |

- 三者有少量**有意重叠**（时间线 / 同好会 / 说话方式）：世界书要关键词才出现，记忆书必须一直在
- 剧情检索按角色：放自己的 `story_index.json.gz` 就用它；`story.json` 里 `enabled:false` 直接关
  （**新建角色默认关**，避免捞到和纱的剧情）；都没有才用全局那份
