## 几个必知的坑

1. 只起后端必须带 `WA2_ASSETS_DIR`，否则 `/game/assets/**` 404；在线冒烟里用 `WA2_NO_MODELS=1` 避免拉起 GPT-SoVITS。
   **`main.py --serve-only` 跑的是 `build_env/` 里的拷贝**：改完 `src/*.py` 一定要先
   `python tools/run_dev.py --sync-only`，否则测的还是旧代码（这一坑害我白测了三遍）。
2. 前端改了要 **bump `index.html` 的 `?v=`**，否则 WebView2 用旧缓存。
3. 探针 `--js/--check` 收**文件路径**，脚本要包成 IIFE（顶层 `return` 会报错）；不要输出截图，看 JSON 数字。
   **正文被字模渲染器换成了 `<img>`，读 `textContent` 会是空的——要读 `data-uitxt`。**
4. `run_state.json` 是「本次运行」标记：强杀会留下，下次启动提示「上次没有正常退出」——设计行为。
5. 演出过渡开关是 `prefs.json` 的 `xfade` / `xfadeMs`（200~300），菜单「环境设置 → 演出过渡」。
6. 改「调了会变行为」的数字先看 `other/docs/参数与指标.md`；改完 `param_table.py --write` + `test_params.py`。
7. 提交前跑 `run_smoke.py`：31 份自测（35 项），前端拆分告警基线钉在 91，涨了就是这次带进来的。
   **窗口全屏 / 最大化点了没反应**先看 `tools/test_window_api.py`：接口回 200 但 body 里是
   `module 'main' has no attribute '_WINDOW'` 就是主模块名拿错了（坑二）。
8. 日志留 14 天（`WA2_LOG_KEEP_DAYS`），`/api/text` `/api/tts` 查询串不落日志；分享用「帮助 → 导出诊断包（默认不含对话）」。
9. 性能采样写 `logs/perf-<日期>.csv`（每 20 轮，`WA2_PERF=0` 关）；像素对齐差 >1% 退出码 1。
10. `memory/standing.json`（常驻记忆书两段化）**本地数据**：删掉即回落到 `memory/*.txt`，
    改过 txt 想重新抄一遍也是删掉再等关系阶段变化（阶段 1 不生成，失败冷却 30 分钟）。
11. 演出 / 切片可配：`performance.json`（`fade_ms` / 情绪→表情 / 场景→衣服）和
    `persona_slices.json`（原作检索与世界书预算）都**只写覆盖值**，缺项用代码默认；
    写错只弹一次 toast + WARN，不会崩。前端 `WA2.perfCfg` 启动和切角色各拉一次 `/api/performance`。
12. 素材热重载：素材 / 角色文件夹一变，约 7 秒内画面自己换新（勾子失败保留旧图并记 WARN）；
    `WA2_HOTRELOAD=0` 关掉。缺什么看菜单「环境设置 → 素材检查」（向导只提示，不替你导入）。
13. **临时文件一律放 `program/work_scratch/`**（已 `.gitignore`）：`run_smoke.py` 会把子进程的
    `TEMP/TMP` 指到 `work_scratch/tmp`，跑完自己收走。别再用系统 `%TEMP%`——用户明确说过不想在
    C 盘看到这些（之前堆了 430 MB）。手动跑单份自测时也要先 `$env:TEMP=<program>\work_scratch\tmp`。
14. 剧情检索（`story_rag`）**只在话里出现剧情锚点时触发**（`STORY_HINTS`：记得/以前/结局/学园祭/
    车祸/第二音乐室/毕业…）。闲聊不注入；要扩召回就加词，别把门槛整体调低（会把「今天好冷」也塞进剧本）。
    索引块带 `〔标题行〕`，重建后记得复制 `.gz` 到 `build_env/`（`run_dev` 只同步 `.py`）。
    **v3 索引**（`story_index_v3.json.gz`，8792 块）每块带 `period/route/tags`，
    `memory_context(period=, tags=)` 会加权并让同标签块优先占位；重建用
    `python other/dev/work/build_index_v3.py`，同样要复制到 `build_env/`。
    说话风格参考 `prompt/style.txt` 由 `other/dev/work/extract_style.py` 生成，**别手改**。
15. 角色内容分三层，**同一件事只放一层**：提示词（每轮必带，身份/说话/规则）→ 记忆书（每轮必带，
    ≤1500 字，她记得的事件）→ 世界书（关键词触发，≤4 条/1200 字，资料卡）。
    跨路线提炼的人设放提示词；各条结局线做成世界书条目（`结局线·…`），内容开头写明
    「资料、不是现在」，被问起时用「那条线里」的口气——别让某个结局变成正在发生的事。
16. 模型偶尔把标签拼错（`</emomotion>`）；`text_parse.split_emotion` 已把闭标签放宽到 `</?emo…>`。
    再遇到漏字先进这个文件看正则，别急着重写解析。
17. **情绪标签要当「不可信输入」处理**：模型经常整句不写 `<emotion>`（实测 5 句里 2~4 句没有），
    而且改词表顺序只会把偏置挪到另一个词（把毒舌排第一，平常句就被标成毒舌）。
    现在 `split_emotion` 会在缺标签时按台词形态猜，来源记在 `LAST_EMO_SOURCE`
    （`tag/inferred/default/override`），`api_chat` 打一行「情绪标签推断/缺失」。
    **别再把它改回「没标签就 calm」**——那会让参考音频和立绘表情一起瘫在 calm 上。
18. **语音名字读错先看 `characters/<角色>/pronunciation.json` 在不在**：读音替换只读这份数据，
    代码里不写死任何角色名。角色包导出/导入**不带**它，重整过角色文件夹就会丢（2026-11-05 就是这么丢的）。
    映射表按 mtime 缓存，补完不用重启。
19. **台词是双语输出，别再单独去翻**：模型一次给
    `<emotion>…</emotion><action>（中文动作）</action><ja>日语</ja><zh>中文</zh>`，
    `split_bilingual()` 拆开 —— ja 给 TTS（`speak_ja`）、zh 给字幕。
    只有模型**没给 `<zh>` 或不像中文**时才走 `translate.py` 兜底（云端 → 本地 Hy-MT2）。
    谷歌免费端点实测 **429**，别浪费时间接；云端翻译必须 `reasoning_effort=none`
    （否则 `max_tokens` 会被 reasoning 吃光、`content` 为空）。
    人名靠角色文件夹的 `translation_glossary.json`（`{"to_zh": {"春树": "春希"}}`，长键优先）纠正。
20. **回想重播慢 ≠ 缓存坏了**：TTS 缓存 key 是 `text|lang|emotion|参考音频签名`
    （文件在 `program/cache/tts`，启动时清空是设计行为）。重播必须用**这句当时的情绪**
    （`row.dataset.emo` / `history[i].emo`），以前写死 `neutral`，于是每次都 miss、重新合成 2~5 秒。
    排查看日志那行 `TTS 合成: N 字节, 耗时 0.0s`——0.0s 才是命中。
21. **「字幕长、语音短」先分清是合成截断还是文本本身长度差**：合成端 `cut5` 不截断
    （实测 1 句 1.56s / 2 句 3.24s / 3 句 6.70s；`cut0` 才会截断，别改）。
    `text_parse.ja_clean()` 以前**无条件按第一个句号取第一句**、还会从句中逗号砍，
    两句台词会被砍成半句——已修。旧版字幕是另一次翻译的产物，字数本来就对不上；
    现在字幕是模型自己写的 `<zh>`。
22. **「素材已更新」狂弹不是推送，是轮询把运行时数据当成了素材**：后端 2 秒扫一次
    assets + 当前角色目录算签名，前端 4 秒轮询 `gen` 变了就弹。角色目录里的
    `sessions/`（自动存档/缩略图）和 `memory/standing.json` 聊天时一直在变，于是几秒弹一次。
    现在 `hotreload.SKIP_DIRS`（sessions/cache/_deleted/logs/…）与 `SKIP_FILES`（standing.json）
    不参与签名，前端提示也节流到 15 秒一次；放真素材（portrait/voice）仍然立刻生效。
