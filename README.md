## 版本与回滚

**一键更新（推荐）**：程序启动后若发现新版本，标题栏会弹「发现新版本 x · 点此一键更新」，
点一下就会自己更新到最新代码（有 `.git` 走 `git fetch + reset --hard`，zip 安装则下载整份快照，
只覆盖代码与文档，不碰角色、素材、存档），完成后关掉窗口重开即可。
**不用管自己漏了几版** —— 它不是打补丁，而是直接取最新整份代码。

| 用途 | 命令 / 位置 |
|---|---|
| 旧版代码锚点 | tag `v2026-11-02-old`（框架更新之前的最后一版） |
| 看旧版代码 | GitHub：`.../tree/v2026-11-02-old/program/src` |
| 手动打补丁（不想自动更新时） | `git apply "other/docs/patches/<日期>_更新补丁.patch"`（基线写在补丁文件头与更新日志里） |
| 已经是最新、想退回旧版 | `git apply -R "other/docs/patches/2026-11-03_回滚补丁_代码.patch"` |
| 整个工作区硬退回旧版 | `git checkout v2026-11-02-old -- program` |

> 补丁和旧版 tag 都会保留，不会因为发布新版被删掉。

## 它是什么 / 不是什么

**是**：一个 pywebview + WebView2 的桌面程序，做成游戏的界面骨架（标题画面、对话框、存档/读档、回想），
把「对话、翻译、语音」串成一条本地流水线，用来像在galgame里面聊天一样。

**不是**：

- ❌ 不附带游戏本体、立绘、CG、BGM、语音、字体等**任何游戏资源**
- ❌ 不附带任何模型权重（TTS 权重、翻译模型都不在仓库里）
- ❌ 不提供破解、不提供反盗版绕过、不提供一键整合包
- ❌ 不是"让游戏角色复活"的产品，只是一个聊天界面的技术验证

---

## 架构

```
对话   deepseek-flash（云端，DeepSeek 官方 API）
翻译   Hy-MT2-1.8B（本地 llama.cpp / Ollama，日→中）
语音   GPT-SoVITS v4 + 第三方分享的和纱音色权重（本地服务）
界面   pywebview + WebView2，800×450 舞台等比缩放
```

云端只负责「说什么」，本地负责「怎么翻译、怎么念、怎么画」。

## 没有素材能不能跑

**能，但只有骨架。**

仓库里只有代码，`clone` 下来直接跑会缺素材。程序的设计原则是：

1. **从不下载游戏资源**，也不联网抓取素材
2. 素材需要用户**自己从正版游戏目录**里提供
3. 缺素材时给出占位（纯色块、系统字体），逻辑照常运行

把素材补齐只有一条合法途径：**自己购买游戏本体**，用自己手上的文件。

> 仓库里不包含解包工具的成品，也不写绕过保护的方法；
> `other/dev/` 下的脚本是本地开发时用的，未入库。

## 关于模型：哪些是我训的，哪些不是

这一段是为了说清楚责任边界，避免误解。

| 组件 | 谁训的 | 在仓库里吗 |
|---|---|---|
| **对话模型**（deepseek-flash） | 云端 API，第三方提供 | —（走 API 调用） |
| **翻译模型**（Hy-MT2-1.8B） | 第三方开源模型 | ❌ 不包含 |
| **语音模型**（GPT-SoVITS + 和纱音色权重 `Touma_Kazusa`） | **不是本项目训练的**，是社区作者训练并公开分享的权重 | ❌ 不包含，也不转存、不镜像、不二次分发 |
| **语音训练语料** | 不属于本项目 | ❌ 不包含 |

也就是说：**语音这条线上，本项目只做"调用方"**——把文本发给本地的 GPT-SoVITS 服务，拿回音频播放。
音色权重从哪来、怎么训练，与本项目无关；本项目也不提供该权重的下载。

如果你要复现语音部分，需要自行获取可用的 TTS 权重并自负其责。
